## Project Overview

For this assignment, I chose Python to create a simple security application. The application demonstrates hashing, encryption, decryption, and digital signatures.

## Features

### 1. SHA-256 Hashing
The application generates SHA-256 hashes for text entered by the user. It can also generate hashes for files. Hashing helps check whether information has been changed.

### 2. Caesar Cipher
The application uses a Caesar cipher to encrypt and decrypt text. It shifts letters through the alphabet using a number selected by the user.

### 3. Digital Signatures
The application uses RSA keys to create and verify digital signatures. The private key signs a message, and the public key verifies the signature.

## Requirements
- Python 3
- Cryptography library

Install the library using:

py -m pip install cryptography

## How to Run
1. Open the project in Visual Studio Code.
2. Open the terminal.
3. Install the cryptography library.
4. Run the program using:

py security_toolkit.py

5. Select an option from the application menu.

## Conclusion

This project helped me understand basic computer security concepts, including SHA-256 hashing, Caesar cipher encryption, and RSA digital signatures.
